# 🍅 トマト宇宙農園 — TOMATO STAR FARM

トマト × 宇宙 × 農業。牧場物語のような、小惑星のトマト農場ゲームです。

**遊びかた：`トマト宇宙農園.html` をダブルクリックするだけ。**
（ブラウザで開きます。インストール不要・通信ゼロ・外部ファイルゼロ。
　絵も音もぜんぶプログラムが描いて鳴らしています）

---

## 話

西暦2387年。地球のトマトは疫病でほとんど絶えた。
あなたは祖母が遺した小惑星農場「ソラナム」に降り立つ。
遺品は、種の入った缶と、書きこみだらけの帳面ひとつ。

ホログラムになった祖母（オババ）に教わりながら畑を広げ、
交配を重ね、帳面の最後のページにだけ書かれていた
虹色のトマト『ギャラクシア』にたどりつくのが目的です。

## 操作

| キー | すること |
|---|---|
| 方向キー / WASD | 歩く |
| Shift | 走る |
| **Z / スペース** | つかう・話す・収穫する |
| **X / Esc** | やめる・とじる・メニュー |
| Tab / Q / E | 道具をかえる |
| 1〜0 | 手持ちの枠を直接えらぶ |
| I | もちもの　P 図鑑　J 依頼　H あそびかた　F 音の入切 |

スマホ・タブレットでも遊べます（画面に十字キーとボタンが出ます）。

## はじめの流れ

1. 家を出る（下へ歩く）
2. クワ（1番）で畑を耕す
3. アカホシの種を手に持って、耕した土にまく
4. 水タンクでじょうろに水を汲み、毎日水をやる
5. 実ったら Z で収穫。**出荷箱**に入れれば翌朝おかねになる
6. 夜は家のベッドで寝る（寝ないと26時に倒れて損をします）

## 宇宙ならではの仕掛け

### 重力コンソール（畑の人工重力を変えられる）

| 重力 | 実の大きさ | 糖度 | そのほか |
|---|---|---|---|
| 0.3G 微小重力 | ×1.55 | −3 | 茎が倒れる（支柱が要る） |
| 0.6G 低重力 | ×1.22 | −1 | たまに倒れる |
| 1.0G 標準 | ×1.00 | ±0 | 地球と同じ |
| 1.4G 高重力 | ×0.80 | +4 | 育つのが遅い |

大きくして数で売るか、小さく甘くして等級で売るか。毎シーズンの判断になります。

### 軌道季（4つの季節が14日ずつ、1年56日）

- **陽季** 光が強い。恒星フレアが多い
- **嵐季** 砂嵐と隕石雨。石が畑に転がる（隕鉄が拾えることも）
- **霜季** 凍る。フロストベル／ブラックホール以外は土壌ヒーターが要る
- **影季** 昼が来ない。ネビュラ以外は育成ライトが要る

### 恒星フレア

シールドが無い日にフレアが来ると、作物が**変異**します。枯れることもありますが、
**買えない品種「コスモブルー」はこの変異からしか手に入りません。**
守るか、賭けるか。

### 交配（Dr.ルナの研究端末）

```
アカホシ ── コメット ──→ サンフレア
   └── サンフレア ──→ ジュピター
コメット ── サンフレア ──→ フロストベル
サンフレア ── フロストベル ──→ ネビュラ
ジュピター ── フロストベル ──→ ストームハート
ジュピター ── ネビュラ ──→ ブラックホール
ブラックホール ── コスモブルー ──→ ★ギャラクシア
```

同じ品種どうしを掛けると「選抜種」になり、等級（★）が上がりやすくなります。

### そのほか

- **加工小屋** ジュース／ケチャップ／ドライ／パスタソース／ワイン。値が最大6.4倍に
- **坑道** 地下10層まで。鉄くず・シリコン・ヘリオ結晶を掘って設備を強くする
- **温室** 修理すると、いつでも陽季・1.0G・水やり自動
- **依頼ボード** 毎朝入れ替わる。住民と仲良くなると値引きや差し入れがある

## つくりかた（中身をいじりたい人へ）

```
src/00_data.js    品種・アイテム・住民などのデータ
src/10_art.js     ドット絵（全部コードで描いている。画像ファイルは1枚も無い）
src/20_audio.js   BGMと効果音（WebAudioで合成。音声ファイルも無い）
src/30_world.js   地図と置いてあるもの、坑道の自動生成
src/40_state.js   状態・もちもの・セーブ
src/50_player.js  操作・歩く・使う・会話
src/60_farm.js    農業の処理と「一日が終わる」処理
src/70_ui.js      メニュー・会話ウィンドウ・図鑑
src/80_render.js  描画・明かり・天候・タイトル・エンディング
src/90_main.js    起動と主ループ
```

```bash
python3 build.py    # src/*.js をまとめて トマト宇宙農園.html を作りなおす
node check.js       # ブラウザ無しで自己検査（地図・データ・1年間の自動プレイ・全画面の操作）
python3 shots.py    # ヘッドレスChromeで shots/ に画面写真を撮る
python3 play.py     # 自動操縦。ブラウザの中で実際に5日ぶん遊ばせて play/ に記録する
```

`play.py` は `play_script.js` の手順どおりに**本物のキー操作でゲームを動かします**
（家を出る→耕す→まく→水を汲む→水やり→寝る→4日育てる→収穫→出荷→精算→中央区で買い物）。
仕様変更のあとに流すと、詰まった場所が「⏱ 時間切れ」として出るので、通しで遊べるかの確認になります。

`トマト宇宙農園.html` だけあれば遊べます。src/ は作りなおすときだけ必要です。

## セーブについて

ブラウザの保存領域（localStorage）に自動保存されます。
寝るたびに保存され、メニューからも手動で保存できます。
**別のブラウザで開くと別のセーブになります**。いつも同じブラウザで開いてください。
