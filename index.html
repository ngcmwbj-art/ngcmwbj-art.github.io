世界のうしニュース 投稿ツール

最終更新: 2026年9月19日

このページは、YouTubeチャンネルおよびTikTokアカウント「世界のうしニュース」の運営者（以下「提供者」）が、 自分で制作した動画を自分のアカウントへ投稿するために使っている個人用ツール（以下「本ツール」）の プライバシーポリシーと利用規約です。

プライバシーポリシー

1. 本ツールの性質

本ツールは提供者本人だけが使う投稿用のプログラムです。第三者に配布・公開しておらず、 提供者以外のユーザーは存在しません。本ツールが扱う動画は、すべて提供者自身が制作したものです。

2. 取得する情報

本ツールは、提供者自身のアカウントに対して、次のAPIを通じて情報を取得・利用します。

サービス利用する範囲（スコープ）目的
YouTube Data API / YouTube Analytics API youtube.upload, youtube.force-ssl, youtube.readonly, yt-analytics.readonly 提供者のチャンネルへ動画を投稿し、題名・説明を編集し、再生数と視聴維持率を確認する
TikTok Login Kit user.info.basic 提供者自身のアカウントを識別する（open id・表示名・アバター）
TikTok Content Posting API video.upload（将来 video.publish） 提供者が制作した動画を、提供者自身のTikTokアカウントへ下書きとして送る（将来は直接投稿する）

本ツールは、他のユーザーの情報・連絡先・視聴履歴などを取得しません。

3. 保存する情報と保管場所

本ツールが保存するのは、上記APIの認証用トークン（リフレッシュトークン）のみです。 これらは提供者個人のパソコン内のファイルにだけ保存し、本人以外が読めないようアクセス権限を制限しています。 アクセストークンは保存せず、必要なときにその場で取得して破棄します。

トークンおよび取得した情報を、外部のサーバーへ送信・保管することはありません。第三者へ提供・販売することもありません。

4. AIの利用について

「世界のうしニュース」の動画は、公開されているニュースを提供者が選び、台本・ナレーション・画面をAIと自作のプログラムで制作しています。 TikTokへ投稿する際は、AI生成コンテンツであることを適切に表示します。

5. データの削除

提供者は、Google アカウントのセキュリティ設定、および TikTok アプリの「設定とプライバシー › セキュリティ › 連携済みアプリ」から、 いつでも本ツールの連携を解除できます。解除後、本ツールが保存しているトークンは無効になり、提供者が手動で削除します。

6. 変更

このポリシーを変更するときは、このページを更新します。

利用規約

  1. 本ツールは提供者本人の利用に限ります。第三者への提供・貸与・再配布は行いません。
  2. 本ツールで投稿する動画は、すべて提供者が制作したものです。他者の著作物を無断で投稿することはありません。
  3. 本ツールは、YouTube および TikTok の各利用規約・開発者規約・コミュニティガイドラインに従って運用します。
  4. 本ツールの利用により生じた結果について、提供者自身が責任を負います。
